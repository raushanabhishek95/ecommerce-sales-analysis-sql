# 🛒 E-Commerce Sales Analysis Using SQL

> A SQL-based data analytics project using MySQL to analyze e-commerce sales, revenue, product performance, category performance, customer behavior, and sales trends.

---

## 📌 Project Overview

The **E-Commerce Sales Analysis Using SQL** project analyzes transactional e-commerce data using **MySQL** to generate business insights and answer practical Data Analyst questions.

The project works with four relational tables:

* `customers`
* `orders`
* `order_items`
* `products`

The analysis covers **sales performance, revenue, products, categories, customers, and time-based trends**.

---

## 🎯 Business Objectives

* Analyze total sales and revenue
* Calculate key KPIs such as Total Revenue and Average Order Value
* Identify top-selling and top revenue-generating products
* Analyze category-wise sales and revenue
* Identify top customers and high-value customers
* Analyze daily, monthly, and hourly sales trends
* Calculate cumulative revenue
* Identify products with no sales
* Rank products within each category
* Calculate category revenue contribution
* Segment customers based on spending

## ▶️ How to Run

1. Install **MySQL Server** and **MySQL Workbench**.
2. Clone this repository.
3. Open `sql/ecommerce_sales_analysis.sql` in MySQL Workbench.
4. Create the `EcommerceDB` database.
5. Import the CSV files into their respective tables.
6. Execute the SQL queries to reproduce the analysis.
